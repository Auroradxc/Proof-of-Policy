# 冒烟测试（一条最小但完整的链路：ONNX → settings → 编译 → SRS → setup
# → witness → prove → verify）已实测通过：全部步骤 OK，verify() -> True，
# 证明 21 KB，端到端约 5 秒。

# 两个实测踩到的坑，P2-9 必须避开：
#   1. 导出的 ONNX **不能带 dynamic_axes**（符号维度会让 tract 前端报
#      "Undetermined symbol in expression: <Sym0>"）。所有维度必须常量 ——
#      这与 P2-9「特征在图中派生」的设计一致（输入形状固定）。
#   2. `torch.onnx.export` 在 torch ≥2.9 默认走 dynamo 导出器；本栈用
#      `dynamo=False`（legacy TorchScript 路径）验证通过。
