## G. ⚠️ §4 的推理是非因果的（**新增，优先级最高**）

### G.0 问题

`docs/sp1-zk-audit.md` §4 与 `bench/comparison_zkagent.md` §4.4 都写着这条推理：

> 「自然语言响应的熵远低于 SHA-256 的 256 bit（一句话 T 的信息量通常在 ~10²–10³ bit 量级，且高度受上下文约束），**因此枚举是可行的**。」

**「熵远低于 256 bit」推不出「枚举可行」。** 2¹⁰⁰ 与 2²⁵⁶ 一样枚举不了。按文档自己给的 10²–10³ bit，字典攻击**恰恰不可行**——现在这条论证是自相矛盾的，写进论文一句话就被拆。

### G.1 正确的推理

真正的攻击不是遍历字符串空间，是**重执行**：对手的已知信息不是"响应空间"，而是 **(prompt, 模型, 解码参数)**。给定这三者，贪心/低温解码下响应**近乎确定**，猜测熵 `k = −log₂ Guess(T ∣ prompt, M, decode) ≈ 0`（`Guess` 取**平均**条件猜测概率；`k` 是**测量值**）。攻击成本 = 一次推理，**与响应长度无关**。

## I. ⚠️ 定理陈述本身的两处缺陷（**新增，2026-10-12 自检产出，优先级与 G/H 同级**）

> **来源**：`docs/tdsc-plan.md` §1.6(e) 那 6 周自检**当日执行完毕**。产出不是"证明写完了"，而是**发现两条陈述本身有问题**。落盘处：`docs/security-model.md` **§4.5**（定义、反例、T1-H 完整证明、T3′ 游戏与证明、T2 停用理由、统一脊梁表）。

### I.0 为什么单开一组

G 组改的是**推理**（非因果），H 组改的是**命题**（"绑定不上"作废）。I 组改的是**定理陈述的正确性**——比前两组更靠里：命题错了论文是弱的，**定理写错了论文是错的**。

### I.1 T1 的原陈述**是假的**，必须补一条结构性假设

**事实认定（非推测）**：原 T1 写作"`A` 被给 `Z`，可评估 `β` 至多 `q` 次 ⇒ `Pr[A(β(T),Z)=T] ≤ q·2^{−k}`"。**取 `β = id`（或本文的 `β = encode(T)`）：`A` 输出 `β(T)`，成功率 = 1**，与 `q`、`k` 无关 ⇒ 该陈述对任意公开 `β` 为假。

**修改点**：

| # | 位置 | 改法 |
|---|---|---|
| I1 | `paper/tdsc-skeleton.tex` T1 | 拆成两制式：**(H)** 需假设 `β(T)=H(dom‖u32be(len(n))‖n‖T)`、`H` 为 RO、`n` 与 `T` 独立 ⇒ `q·2^{−k}+q·2^{−λ}`；**(L)** 任意确定 `β` ⇒ 界落在**原像类**猜测概率 `Guess(T∣Z,β(T))` |
| I2 | 同上，`k` 的定义 | 换成**猜测熵** `k = −log₂ Guess(T∣Z)`，`Guess(T∣Z)=E_z[max_t Pr[T=t∣Z=z]]`（Dodis–Smith **平均**条件最小熵，**可测**）。**不得**用逐点最坏 `k_z` 再取 `max_z` —— 证明里取期望那一步 Jensen 方向会反 |
| I3 | 同上，`prop:semantic` | 改写为 **T1(L) 的实例**（`encode(T)` 正好违反 (H) 的假设）。这条正是"补假设反而把两个实例收进一条定理"的收益 |
| I4 | 全文任何写 `H_∞(T∣Z)` 的地方 | 统一改为 `−log Guess(T∣Z)`，并注明它是**测量值**不是假设值 |
| I5 | 诚实边界 | T1-H 只在 **ROM** 下成立；SHA-256 只给计算意义下的近似 ⇒ 措辞必须是 **heuristic**，**不得**写成信息论界 |

**收益**：本文自己的两个公开值（`response_binding`、`encode(T)`）**正好分居这条假设的两侧** ⇒ "为什么响应绑定能隐藏、而语义规则不能"从一句观察变成**一条定理的两半**。

### I.2 T2 **是空的**，必须停用（不是"难证"，是"无内容"）

**事实认定**：原 T2 声称"存在同时取得绑定与隐藏的方案**当且仅当**验证是指定验证者"。两方向都不成立：

- `⇐`（指定验证者 ⇒ 可隐藏）**假**：`k ≈ 0` 时**任何**方案（含指定验证者）都无隐藏——对手**重执行模型**即可，不需要看证书。
- `⇒`（公开可验证 ⇒ 无隐藏）**真，但理由与"公开可验证"无关**，同样只用到 `k`。
- ∴ 二分法由 `k` 单独决定，**没有独立内容**。

**修改点**：

| # | 位置 | 改法 |
|---|---|---|
| I6 | `paper/tdsc-skeleton.tex` `thm:t2` | **删除定理环境**，改为 `Remark{rem:designated}`：本系统验证接口是**指定验证者形状**，这是**设计选择**，不是被不可能性逼出来的唯一选择 |
| I7 | 同上，intro 贡献列表 | 去掉"给出 a separation"；**增补一段"我们不主张的分离"**——显式写明为何不主张（低 `k` 下每种方案都无隐藏）。**主动写出否命题更难写、我们没写**，比被审稿人问出来好 |
| I8 | `docs/security-model.md` §4.5.6 | 保留完整停用理由与"残留的真问题（投递可审计性 vs 隐藏）"的界定 |

**收益**：撤掉一条**会被一枪打死**的定理，换成一条**站得住的观察**。审稿人若发现 `⇐` 方向假（重执行即可，门槛很低），整篇的定理可信度会连带受损。
