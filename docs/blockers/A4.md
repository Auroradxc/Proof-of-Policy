## 1. 证据：为什么说 Docker 不可用

```text
$ docker --version
The command 'docker' could not be found in this WSL 2 distro.
We recommend to activate the WSL integration in Docker Desktop settings.
...
exit 1
```

Windows 侧的 Docker Desktop **客户端**存在（`/mnt/c/Program Files/Docker/Docker/resources/bin/docker.exe`，
版本 28.1.1），但 Linux engine 连不上：

```text
Client:
 Version:           28.1.1
 Context:           desktop-linux
error during connect: Get "http://%2F%2F.%2Fpipe%2FdockerDesktopLinuxEngine/v1.49/version":
open //./pipe/dockerDesktopLinuxEngine: The system cannot find the file specified.
```

即：**Docker Desktop 没有启动，或没有为当前 WSL 发行版启用 integration**。
在这种情况下无法构建镜像，也无法给出镜像大小；本文档不声称构建成功。

## 4. 如何解除

在 Windows 侧启动 Docker Desktop，并在
`Settings → Resources → WSL Integration` 中启用当前发行版，然后：

```bash
docker version                       # 应能同时看到 Client 与 Server
docker build -t pop-artifact .
docker run --rm pop-artifact         # 期望：Ran 42 tests … OK
docker images pop-artifact           # 记录镜像大小，回填 README §2
```

若 `docker build` 卡在拉取基础镜像或 `pip install cryptography`，属网络问题，
不是本仓库的 blocker；可重试或配置镜像源。
