## 怎么读

- **温度 0**：响应若确定，`p_max=1`、`k=0` ⇒ 重执行一次模型即可恢复 `T`，与证明系统无关。
- **温度 > 0**：`k` 升高，但自然语言响应的众数仍常占很高比例；要判断证书是否真的隐藏 `T`，看 `k < 阈值` 的比例，而不是看平均值。
- 精确字符串计数会低估长响应的多样性；`N` 只有 20–50。本表是**采样分布的估计**，不是信息论上界。
- `N=50` 的截断：`p_max` 最小只能分辨 `1/50`，故 `k` 的**最大可观测值**约为 `5.64 bit`；所有样本互不相同时只会得到这个上界，而不是真实熵。`k=0` 也可能只是 `N` 太小没采到变体。
- chat template 开启时，prompt 被包成单轮 user 消息，解码只取新 token；关闭时是裸续写（X2 口径）。两种口径的 `k` 与端到端指标不可直接混用。
- 真正的攻击是**重执行**（`Corollary reexec`），不是枚举字符串空间。

### N 截断判读

- 本实验 N=50，因此**任何组的最小可能 `p_max` 都是 1/50 = 0.02**；`p_max < 1/N` 在有限样本内不可能出现。
- 若所有组都 `distinct == 50`，则 `p_max == 1/50`、`k == log2(50) == 5.644 bit`，这只是 **k 的下界**；真实熵未知。
- 只要出现重复（`distinct < 50`），`p_max > 1/50`，`k < 5.644 bit`，此时才得到高于下限的信息（重复频率）。
