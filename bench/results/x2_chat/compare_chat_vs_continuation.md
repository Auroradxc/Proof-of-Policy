# chat-template 口径 vs 续写口径（X2c / X2）

同一台 RTX 5090、同一个 `Qwen/Qwen2.5-7B-Instruct`（fp16）、同一批 20 条 prompt
（`prompts_xstest.jsonl` 分层取 safe 10 + unsafe 10）。端到端每 prompt 取
`sample_index=0`，即**温度 0 的贪心响应**；`k` 的采样数 `N` 在各列注明。

| 指标 | chat template（本任务，N=10） | X2 续写（N=20） | 无模板同批（N=5，复核） |
|---|---:|---:|---:|
| `k`（温度 0） | 0.00 bit | 0.00 bit | 0.00 bit |
| `k`（温度 0.7） | **3.32** bit（= log2 10） | **4.32** bit（= log2 20） | **2.32** bit（= log2 5） |
| 温度 0.7 每组 distinct | 10/10（20/20 组） | 20/20（50/50 组） | 5/5（20/20 组） |
| prompt 级策略 P / R / F1 | 0.500 / 0.800 / **0.6154** | 0.500 / 0.800 / **0.6154** | 0.500 / 0.800 / 0.6154 |
| 响应违规率 | **90%**（18/20） | **100%**（20/20） | 100%（20/20） |
| 拒绝代理率 | **35%**（7/20） | **15%**（3/20） | 15%（3/20） |
| 拒绝代理 P / R / F1 | 1.000 / 0.700 / **0.8235** | 1.000 / 0.300 / **0.4615** | 1.000 / 0.300 / 0.4615 |
| 响应长度 mean / median | **974.9 / 1135** 字符 | **986.6 / 1109.5** 字符 | 986.6 / 1109.5 字符 |
| safe 响应 mean 长度 | 1215.3 字符 | 1186.8 字符 | — |
| unsafe 响应 mean 长度 | 734.4 字符 | 786.4 字符 | — |
| safe 响应被拒 | 0/10 | 0/10 | 0/10 |
| unsafe 响应被拒 | **7/10** | **3/10** | 3/10 |

（对照列：X2 全量 50 prompt 的报告值为响应违规率 96%、拒绝率 10%、长度 mean 978.1；
同批 20 prompt 的数值如上表。）

## 怎么读

1. **`k` 的绝对值被 `N` 截断，三列不可直接比大小。** 每列都恰好等于
   `log2(N)`，含义只是“N 个样本里没有重复”；真实熵可能更高，本数据无法区分。
   可比的结论是**定性**的：两种口径下，温度 0 都确定性（`k=0`），温度 0.7 都
   采不到重复。
2. **chat template 主要改变端到端的“拒绝行为”**：拒绝代理率 15% → 35%，
   unsafe prompt 的拒绝从 3/10 升到 7/10；同时响应违规率 100% → 90%。这说明
   X2 的低拒绝率很大程度上是**续写口径的产物**（模型在续写 prompt，而不是
   回答它），不是对话模型的实际拒答倾向。
3. **prompt 级策略指标不受口径影响**：同一策略包判同一批 prompt，P/R/F1 完全
   相同（0.5 / 0.8 / 0.6154）。它衡量的是策略本身的误报/漏报。
4. **响应长度均值接近，但分布不同**：chat 口径下 safe 回答更长（1215 字符）、
   unsafe 回答更短（734 字符，常以拒绝开头）；续写口径两边都在 ~1200/786 字符。
5. **无模板同批复核**：200 条样本中 100 条温度 0 响应与 X2 **逐字节相同**，
   100 条温度 0.7 响应不同（采样随机性，预期内）；其端到端指标与 X2 同批
   20 prompt 完全一致。这确认了两次运行用的是同一批 prompt、同一模型、
   贪心解码可复现，`--chat-template` 缺省关闭时旧口径未被破坏。
6. **90% 响应违规率不是模型真实有害率**：`safety_xstest_v1` 是关键词策略，
   safe prompt 的正常回答也常被判违规（chat 口径 9/10）。响应级没有 ground
   truth，拒绝率也只是前缀启发式代理，论文里都必须标明。

## 数据来源

- chat 口径：`bench/results/x2_chat/k_samples_chat.jsonl`（400 条）、
  `k_entropy_chat.md`、`real_llm_e2e_chat.md`
- 续写口径：`bench/results/k_samples.jsonl`（X2，2000 条）中的同批 20 prompt 子集
- 无模板同批：`bench/results/x2_chat/no_template/k_samples.jsonl`（200 条）
